How to read this page

A share is worth the cash it will pay its owner, discounted back to today. This page values the S&P 500 on that principle, with inputs refreshed every week, and reports two readings.

Run backwards, the valuation gives the equity risk premium the index level implies: the extra return over Treasuries that makes the value equal today's index. Run forwards, it gives the value under a scenario: what the index would be worth if one stated thing changed. Each scenario below is a rule applied to data, with the numbers shown, not a set of typed assumptions.

A fair value is not a forecast. Most of the value sits in the distant future, so small changes in the discount rate or in growth move the answer a lot. Read the scenarios as distances, not as targets. Not investment advice.

Limits

Analyst estimates are optimistic on average and are revised down more often than up; the valuation takes them as they are. Analyst earnings exclude items companies call non-recurring and run above reported (GAAP) earnings, shown beside them. Most of the value is in the distant future. The scenarios change one or a few things and hold the rest still, which markets do not do. The gap between the earnings yield and the real yield has a history that starts in 2003 and includes a decade of very low real yields, which makes today look expensive against it.
